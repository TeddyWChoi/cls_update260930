# Closers Global — "Audience with the Lord: Baal" update landing (2026-09-29)

One-scroll landing page. Vanilla HTML / CSS / JS, no build step.

- `index.html` — page markup + small inline script (scroll reveal, preview clip autoplay, ember particles)
- `style.css` — all styles
- `assets/` — images (WebP), item icons, dungeon preview clips (`*.mp4`), decorative frames

Preview locally:

```bash
python3 -m http.server 8952
```

Source GIFs for the preview clips are not committed (see `.gitignore`); the MP4s in `assets/` are the delivered versions.
